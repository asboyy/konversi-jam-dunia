# Konversi Jam Dunia (World Clock Converter)

Konversi Jam Dunia adalah aplikasi desktop berbasis Visual Basic .NET yang dirancang untuk membantu pengguna memantau dan mengonversi waktu di berbagai zona waktu global secara akurat. Aplikasi ini sangat berguna bagi mereka yang bekerja dalam tim internasional atau sering melakukan koordinasi lintas negara.

## 🌍 Fitur Utama

- **Real-Time Clock:** Menampilkan waktu saat ini untuk berbagai kota besar di dunia secara sinkron.
- **Konversi Zona Waktu:** Fitur untuk menghitung perbedaan waktu antara zona waktu lokal dengan zona waktu tujuan (misalnya: WIB ke GMT, EST, atau JST).
- **Pilihan Kota Populer:** Daftar drop-down yang memudahkan pengguna memilih zona waktu negara tertentu.
- **Antarmuka Digital:** Tampilan jam yang bersih dan mudah dibaca, mensimulasikan jam dunia profesional.
- **Penyesuaian Otomatis:** Menghitung selisih jam secara otomatis berdasarkan standar waktu internasional (UTC).

## 🛠️ Teknologi yang Digunakan

- **Bahasa Pemrograman:** Visual Basic .NET (VB.NET)
- **Framework:** .NET Framework
- **IDE:** Visual Studio

## 🧠 Konsep yang Diimplementasikan

1. **Date & Time Handling:** Menggunakan fungsi `DateTime` untuk mengambil dan memanipulasi waktu sistem.
2. **TimeSpan Logic:** Menghitung durasi selisih antar zona waktu yang berbeda.
3. **Timer Control:** Memastikan tampilan jam terus diperbarui setiap detik secara otomatis (Tick Event).
4. **Data Selection:** Menggunakan kontrol `ComboBox` atau `List` untuk manajemen data zona waktu.
